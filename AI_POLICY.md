# AI policy

ohmylaya is built with AI coding agents and welcomes contributions made with
them. The rules are about responsibility, not tooling.

- The human who opens a pull request owns every line in it. "The agent wrote
  it" is not an explanation for a defect.
- State material AI assistance in the pull request description: which tool,
  what scope, and how you verified the result. A one-line note is enough.
- Do not list an AI tool as a co-author. An optional `Assisted-by:` trailer is
  fine.
- Generated tests must test behaviour, not restate the implementation.
- Maintainers review AI-assisted work with the same bar as any other work.
  There is no automated AI detection and there will not be.
